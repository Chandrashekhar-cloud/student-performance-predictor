# Student Predictor

Build a simple, clean college mini-project web application called:

"Student Performance Prediction System"

This is an educational machine-learning project. Keep the frontend very simple because I need to complete the project quickly and demonstrate it on a laptop.

Create a single-page responsive web application with these sections:

Header

Project name: Student Performance Prediction System

Small subtitle: "Predict student academic performance using machine learning"

Input section
Create a clean form with these inputs:

Study Hours per Day

Attendance Percentage

Previous Exam Score

Assignment Score

Sleep Hours per Day

Use suitable number inputs and validation.

Predict button
Add a prominent button:
"Predict Performance"

For now, DO NOT connect any backend or real ML model.
When the button is clicked, show a sample prediction result so I can preview the complete UI.

Results section
Display:

Predicted Score

Performance Level

Simple message

Example:
Predicted Score: 78%
Performance Level: Good
Message: "The student is expected to perform well."

Also show a simple visual progress bar for the predicted score.

How It Works section
Show 3 simple steps:
Input Student Data → Machine Learning Model → Performance Prediction

About Project section
Briefly explain that the system uses student academic and lifestyle information to predict expected performance.

Design requirements:

Modern but simple

Professional college-project appearance

White/light background

Blue/neutral accent colors

Rounded cards

Clean typography

Responsive on laptop and desktop

No unnecessary animations

No login/signup

No payment

No database

No external APIs

No complicated features

IMPORTANT:
The frontend should be designed so that later I can easily connect the Predict button to a Python Flask backend.

Use mock/sample prediction data for now.

After building it, make sure all buttons, form fields and navigation work correctly. dont use neon ,use light theme
